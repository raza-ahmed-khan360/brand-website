# American Website Developer

An editorial agency site built as a static HTML, CSS and JavaScript project.

## Preview

```powershell
npm start
```

Open http://localhost:3000. The port can be changed through the `PORT` environment variable.

## Content

- `logo-reference.png` is the logo supplied for this project.
- `assets/portfolio/` contains the 30 portfolio images displayed in five categories: web, logo, branding, motion, and app design.
- `js/main.js` contains the package catalog, interactive filtering, modal views, and form validation logic.
- Business contact details were intentionally left out pending confirmation. No enquiry form or unverified email address is presented.

The site needs final business contact details and a final production review before deployment.
