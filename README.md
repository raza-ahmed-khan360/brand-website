# American Website Developer

An editorial agency site built as a static HTML, CSS and JavaScript project.

## Preview

```powershell
npm start
```

Open http://localhost:3000. The port can be changed through the `PORT` environment variable.

## Content

- `logo-reference.png` is the logo supplied for this project.
- `assets/portfolio/` contains the 30 portfolio images displayed in five categories. These were sourced from the public Brand Verse Studios portfolio at the user's request. The site labels them as reference imagery.
- `js/main.js` contains the package catalog transcribed from the Brand Verse Studios packages page and checked on October 21, 2026. Published prices may change.
- Business contact details were intentionally left out pending confirmation. No enquiry form or unverified email address is presented.

The site needs final business contact details and a decision on licensed portfolio usage before production publishing.
